# 법령·법원 서식 채우기 (law-forms)

서식을 두 층으로 다룬다.

| 층 | 대상 | 동작 |
|---|---|---|
| 서식 서재 | 자주 쓰는 서식 | 변환을 마친 hwpx, 칸 매핑(`recipe.json`), `노하우.md`를 미리 둔다. 필드 이름으로 값만 주면 채운다 |
| 요청 시 검색 | 그 밖의 서식 | 법제처 API(법령 별지서식) 또는 court-forms(법원 전산양식)에서 받아 kordoc으로 바꾼 뒤 채운다 |

서재는 개인 서재(`~/law-forms/library`)를 먼저 보고, 없으면 공용 서재(`~/law-forms/shared-library`)를 본다. 사용자 노하우는 개인 서재에 쌓는다.

## 절차

1. **서재 확인** — `~/law-forms/scripts/law_forms.py library list`. 맞는 서식이 있으면 `library show <id>`로 필드와 노하우를 읽는다.
2. **서식 고르기** — 같은 이름의 서식이 여럿이면 제출 기관과 용도를 확인해 고른다.
   - 예: 동석신청서는 공소청(공소청사건사무규칙 제36호·제37호)과 경찰(경찰수사규칙 제25호·제26호)이 다르다.
   - 예: 초본 신청은 소송·집행 목적이면 주민등록법 시행규칙 제7호, 소송 외 채권·채무 관계면 제11호.
3. **값 만들기** — 사건 정보(JuriSupport·사건기록)에서 recipe 필드 이름으로 값 JSON을 만든다. 모르는 값은 지어내지 말고 묻는다.
4. **채우기** — `law_forms.py fill <id> --data 값.json --out both -o <사건 폴더>`.
5. **결과 점검** — 출력 JSON의 `못_채운_빈칸`, `주의`(권장 글자 수 초과·잘못된 선택지), `경고`(쪽수 불일치)를 확인한다. 쪽수가 늘면 값을 줄이거나 별지로 넘긴다.
6. **전달** — hwpx와 PDF 경로를 알린다. PDF는 kordoc 렌더라 글자 간격이 어긋날 수 있으므로 제출 전 한글에서 열어 확인하게 한다.

## 서재에 없는 서식

```bash
law_forms.py search 동석신청서 [--law 경찰수사규칙]     # 법제처, 삭제 서식 제외
law_forms.py get "경찰수사규칙:002600"                   # 받기 + hwpx 변환 + 칸 목록
law_forms.py fill "경찰수사규칙:002600" --data 칸값.json --slots 바꾸기.json -o 출력폴더
```

- 법원 서식(재판기록 열람·복사 등)은 법제처에 없다. 재판예규가 [전산양식 A2200]처럼 가리키므로 `court-forms`로 받아 파일 경로를 넘긴다: `law_forms.py fill "/경로/A2200.hwp" ...`
- 칸 키는 `get` 결과의 라벨을 쓴다. 같은 라벨이 여러 번이면 배열로 순서대로 준다.
- `--slots` JSON의 `replace`는 자리표시 글자(「000」, 「□ 열람」, 「20 . . .」)를, `slots`는 공백으로 된 빈칸(「귀청 형제 호」)을 바꾼다.
- 다 채운 서식이 쓸 만하면 서재에 올린다: `law_forms.py library add <id> --from <키 또는 파일> --recipe recipe.json --notes 노하우.md`

## recipe.json 필드 방식

| how | 쓰는 곳 | 주요 키 |
|---|---|---|
| fill | 표 칸 | key, index |
| fill_list | 표의 열 아래 여러 행(예: 서류 등의 목록) | key, max_rows |
| replace | 라벨과 값이 한 칸에 있는 곳, 자리표시 글자, 날짜 | find, template(`{value}`) |
| slot | 공백 빈칸 | before, after |
| check | 체크박스 줄 | line, mark, checked, options(목록 또는 별칭→문구) |

- 필드마다 `limit`(권장 글자 수)와 `설명`을 둘 수 있다.
- `빼는_부분`: 내지 않아도 되는 안내 쪽. `{"표_포함": "처리절차"}`는 hwpx·PDF 모두에서, `{"pdf_쪽": [3]}`은 PDF에서만 뺀다. `--all-pages`로 남길 수 있다.
- `기준_쪽수`: 공식 PDF가 없을 때 쪽수 대조 기준.

## 노하우 쌓기

사용자가 "이 서식은 이렇게 쓴다"고 말하면 그 서식의 `노하우.md`(개인 서재)에 적는다. 칸 쓰는 법이 바뀌면 `recipe.json`의 설명·권장 글자 수를 고친다. 노하우에는 실제 사건명·의뢰인 정보를 넣지 않는다.

## 주의

- 서재 서식이 개정됐는지 `law_forms.py library check`로 확인한다(법제처 서식만, 공포일자 비교).
- 법령 서식 검색·다운로드에는 법제처 Open API 키(OC)가 필요하다(`LAW_OC` 또는 `~/law-forms/config.json`).
- 원본 서식 파일은 덮어쓰지 않는다. 결과는 출력 폴더에만 쓴다.
- 법원·기관 제출은 사용자가 직접 한다.
