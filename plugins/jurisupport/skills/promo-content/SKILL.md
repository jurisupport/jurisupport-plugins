# 홍보 콘텐츠 묶음 (promo-content)

먼저 [공통 실행 규칙](../../references/runtime.md)을 읽고 현재 호스트에서 사용 가능한 기능으로 수행한다.

법리 하나로 결과물 넷을 만든다. ① 블로그 글 ② 설명 영상 원고(애니메이션형 또는 내레이션형) ③ 컷시트 ④ SNS 짧은 글. 마지막에 광고·공개·비밀 점검표를 붙인다.

## 0. 원칙

- **원문이 먼저다.** 판결·법령은 원문을 열어 대조한 내용만 쓴다. 법령은 korean-law 등 원문 도구, 판결은 사용 가능한 판결 원문 도구로 확인한다. 원문을 열지 못한 내용은 `[미확인]`으로 두고 쓰지 않는다.
- **돈 드는 단계는 맨 뒤다.** 이 스킬은 원고·사실 대조표·컷시트까지 만든다. 이미지·음성·영상 생성(유료 도구)은 사용자가 원고를 승인한 뒤에 따로 한다.
- **실제 사건은 쓰지 않는다.** 사용자가 실제 사건을 소재로 주면, 의뢰인 동의 여부를 묻고 동의가 없으면 누구 사건인지 알 수 없게 바꾼다(당사자·지역·날짜·금액 일반화).
- **금액·승소를 단정하지 않는다.** "받을 수 있습니다", "이깁니다" 대신 판결이 판단한 내용과 조건을 쓴다.

## 1. 작업 폴더

현재 폴더 아래 `promo/<주제-슬러그>/`에 저장한다.

| 파일 | 내용 |
|---|---|
| `01_원문대조.md` | 판결·법령 원문 위치(사건번호·선고일·쪽/문단, 조문)와 핵심 판시 인용 |
| `02_블로그.md` | 블로그 글 초안 |
| `03_쇼츠원고.md` | 18~22문장 원고 + 문장별 사실 대조표 |
| `04_컷시트.md` | 컷마다 화면·그림 프롬프트·정보판 문구·자막 |
| `05_배포글.md` | 쓰레드·인스타 글, 유튜브 제목·설명·해시태그 |
| `06_광고점검.md` | 점검표(4절) |

## 2. 순서

1. **원문 대조.** 판결 전문을 열어 사실관계·쟁점·판단·결론을 정리한다. 판례 변경 사건이면 변경된 종전 판결과 변경 내용을 같이 적는다. 인용은 원문과 글자 단위로 맞춘다. 맞추지 못하면 큰따옴표를 쓰지 않는다.
2. **블로그 글.** 제목 → 한 줄 요약 → 사안 → 법원 판단 → 실무에서 달라지는 점 → 주의할 점 순서. 「판례」 대신 「판결」을 쓴다. 문장 끝에 근거(판결 쪽·문단, 조문)를 붙인다.
3. **쇼츠 원고.** 블로그 글을 18~22문장으로 줄인다. 첫 문장은 시청자가 가진 통념을 뒤집는 질문이나 사실로 시작한다. 마지막 문장은 시청자에게 던지는 질문으로 끝낸다.
4. **사실 대조표.** 원고 문장마다 1차 출처와 대조 결과를 적는다. 줄여 쓸 때 틀어지기 쉬운 세 가지를 따로 표시한다: **주체**(원고·피고·법원), **단위**(원·만 원·%·기간), **시도/성공**(청구했다 vs 인정됐다).
5. **컷시트.** 문장마다 컷 하나를 기본으로 한다.
   - 장면 그림 프롬프트에는 **글자를 넣지 않는다.** 숫자·금액·항목은 「정보판」 문구로 따로 적어 사람이 직접 그리게 한다.
   - **다른 채널·작품의 화면을 참조 이미지로 넣지 않는다.** 그대로 베낀다. 화풍은 말로만 지정한다.
   - 실존 인물·실제 법정·실제 상표를 그리지 않는다.
6. **배포 글.** 같은 내용으로 쓰레드 글(500자 이내), 인스타 캡션, 유튜브 제목(40자 이내)·설명을 만든다. 설명 끝에 「일반적인 법률 정보이며 개별 사건은 사실관계에 따라 달라질 수 있습니다」 같은 고지를 넣는다.
7. **점검.** 4절 점검표를 채운다. 걸리는 표현은 고친 문안을 함께 제시한다.

## 3. 출력 형식

`03_쇼츠원고.md`의 사실 대조표는 아래 열을 쓴다.

| 번호 | 원고 문장 | 출처(판결 쪽·문단 / 조문) | 대조 | 주체·단위·시도/성공 |
|---|---|---|---|---|

`04_컷시트.md`는 아래 열을 쓴다.

| 컷 | 원고 번호 | 화면(그림·정보판·도해) | 그림 프롬프트(글자 없음) | 정보판 문구 | 자막 |
|---|---|---|---|---|---|

## 4. 광고·공개·비밀 점검표

각 항목에 「해당 없음 / 고침 / [미확인]」과 근거를 적는다. 결론을 단정할 수 없는 것은 「변호사 판단 필요」로 남긴다.

| 점검 | 볼 것 | 근거 |
|---|---|---|
| 거짓·과장·오도 | 사실과 다른 표현, 일부만 보여 오해를 부르는 표현 | 변호사법 제23조 제2항 |
| 부당한 기대 | 승소·금액·기간을 약속하거나 단정하는 표현 | 변호사법 제23조 제2항 |
| 다른 변호사 비교·비방 | 「다른 곳은 ~」 식 표현 | 변호사법 제23조 제2항 |
| AI 업무 광고 | 「AI로 사건을 처리합니다」처럼 업무에 AI를 쓴다고 알리는 문구가 있는가. 있으면 변협 규정상 사전 등록·검토 변호사 표시 대상인지 확인 | 대한변호사협회 「변호사 광고에 관한 규정」 제6조 |
| AI 서비스 연결 | 소비자가 AI를 직접 쓰게 하거나 AI에 연결하는 광고인가 | 대한변호사협회 「변호사 광고에 관한 규칙」 제5조 |
| 플랫폼 AI 공개 | 실제로 없던 장면을 사실적으로 만든 컷이 있는가(유튜브 「AI 사용」 공개 대상). 애니메이션·본인 음성 복제 내레이션은 보통 대상 아님 | 유튜브 고객센터 「생성형 AI 콘텐츠 사용 공개」(게시 시점에 다시 확인) |
| 비밀유지 | 실제 사건이면 의뢰인 동의가 있는가, 없으면 식별 불가능하게 바꿨는가 | 변호사법 제26조, 변호사윤리장전 |

규정 조항 번호와 시행일은 게시 전에 원문으로 다시 확인한다. 확인하지 못하면 점검표에 `[미확인]`으로 남긴다.

## 5. 하지 않는 것

- 영상 렌더링·업로드·게시. 게시는 사용자가 직접 한다.
- 원문을 열지 않은 판결의 요지·인용.
- 실제 의뢰인 이름·사건번호·연락처를 검색어나 원고에 넣는 것.
