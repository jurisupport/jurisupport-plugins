# 법률 날짜·금액 계산 (legal-calc)

먼저 [공통 실행 규칙](../../references/runtime.md)을 읽고 현재 호스트에서 사용 가능한 기능으로 수행한다.

**원칙: 날짜와 금액은 계산한 값을 쓰기 전에 반드시 이 스크립트로 계산한다.** 결과에 찍힌 계산식을 보고서·서면 메모에 같이 남긴다. 결과를 손으로 고치지 않는다.

이 `SKILL.md`와 같은 폴더의 `legal_calc.py`를 사용한다. Python 3 표준 라이브러리만 쓴다. 실행 전에 실제 Python 3 실행 방법을 확인한다.

```bash
PY="<이 SKILL.md가 있는 실제 폴더>/legal_calc.py"
python3 -I "$PY" --help
```

## 1. 기간 만료일

```bash
python3 -I "$PY" deadline 2026-10-15 2 주                      # 판결 송달일 → 항소기간 만료일
python3 -I "$PY" deadline 2026-10-15 7 일                      # 즉시항고 등
python3 -I "$PY" deadline 2026-10-01 10 일 --mode criminal --crim-kind 구속기간
python3 -I "$PY" deadline 2026-01-30 1 월 --holidays extra.txt # 임시공휴일 추가
```

- 첫 인자는 **사건일**(송달일·고지일·선고일)이다. 스크립트가 초일 불산입을 적용해 기산일을 정한다. 기간이 오전 0시부터 시작하면 `--include-first`를 붙인다.
- 형사는 `--mode criminal`. 시효·구속기간은 `--crim-kind`로 지정하면 초일 산입, 말일 연장 없음(형사소송법 제66조 제1항 단서·제3항 단서).
- 말일이 토·일·공휴일이면 다음 날로 넘긴다.
- **기간의 길이(2주인지 7일인지)와 사건일은 이 스크립트가 정하지 않는다.** 길이는 korean-law 등으로 조문을 확인하고, 사건일은 송달증명·기록으로 확인한 뒤 넣는다.
- 우편 도달, 전자송달 간주처럼 사건일 자체를 정하는 규정은 따로 확인한다. 스크립트에 넣지 않았다.

### 공휴일

공휴일은 아래 순서로 찾는다.

1. `--holidays` 파일(줄마다 `YYYY-MM-DD 이름`): 임시공휴일을 직접 넣을 때
2. 사용자 캐시(`~/.cache/legal-calc/{연도}.json`, `LEGAL_CALC_CACHE_DIR`로 변경)
3. 한국천문연구원 특일정보(getRestDeInfo)를 k-skill-proxy로 조회(`KSKILL_PROXY_BASE_URL`로 변경, `LEGAL_CALC_OFFLINE=1`이면 조회하지 않음)
4. 플러그인 동봉 자료(`holidays/2025.json`~`2027.json`, 2026. 10. 29. 수신)

- 동봉 자료로 판단하면 `[주의]` 문구가 출력된다. 그 뒤 지정된 임시공휴일은 반영되지 않았으니 만료일 무렵의 공휴일을 확인한다.
- 어느 자료도 없으면 `[미확인]` 문구가 출력된다. 그 결과를 쓰지 말고 공휴일을 확인해 `--holidays`로 넣는다.

## 2. 일수

```bash
python3 -I "$PY" days 2026-10-29 2026-11-12               # 시작일 제외
python3 -I "$PY" days 2025-11-05 2026-10-29 --inclusive   # 양 끝 포함
```

## 3. 이자·지연손해금

```bash
python3 -I "$PY" interest 16,000,000 --seg 2025-11-05:2026-10-29:12 --with-principal
python3 -I "$PY" interest 10000000 --seg 2024-01-01:2024-06-30:5 --seg 2024-07-01:2026-10-29:12   # 이율 바뀌는 구간
```

- 구간은 양 끝 포함 일수로 센다. 1년 = 365일, 구간마다 원 미만 버림.
- 판결 주문이 다른 방식(윤년 366일, 단수 처리)을 정했으면 그에 맞춰 결과를 다시 확인한다.
- **이율은 직접 넣는다.** 확인된 기본값은 민법 제379조 연 5%뿐이다. 소송촉진 등에 관한 특례법·상법상 이율은 쓸 때마다 현행 조문·시행령을 확인한다.
- JuriSupport가 연결되어 있고 사건에 계산을 저장해야 하면 JuriSupport의 집행청구금액·회수비용 계산 도구를 쓰고, 이 스크립트로 같은 값을 교차 확인한다.

## 근거 조문 (국가법령정보센터 원문, 2026. 10. 29. 확인)

민법 제155조~제161조, 제379조. 민사소송법 제170조(기간 계산은 민법에 따름). 형사소송법 제66조.

## 시험

저장소 루트에서 `python3 tests/legal_calc_test.py`. 손계산 기대값 6건(항소 2주, 월말 해당일 없음 + 토·일·대체공휴일 연쇄, 토요일 말일, 형사 구속기간, 2. 29. 기산 1년, 지연손해금)을 네트워크 없이 동봉 공휴일 자료로 대조한다. 스크립트를 고치면 다시 돌린다.
