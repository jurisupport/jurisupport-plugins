# 양식 항목과 기본 문안

원본: `apps/web/src/components/templates/privacy-policy-annex-fields-schema.json` (기준 커밋 fa3c367). 이 표를 고치지 말고 원본이 바뀌면 다시 생성한다.

- `기본(비사용)`: 해당 범위를 쓰지 않을 때의 문안.
- `기본(사용)`: 해당 범위를 쓰지만 구체 사실이 없을 때의 제안 문안(activeDefaultValue).
- 사용자 확인 사실이 있으면 기본 문안보다 우선한다. 기본 문안은 제안이지 확인 사실이 아니다.

## 주제 키 → 양식 항목 연결

| 주제 키·상태 | 채우는 항목 |
|---|---|
| `service.<id>` 중 사건관리·저장·전산 등 위탁 서비스 | `processors`(사용자가 말한 서비스명 그대로), `processingWork`(purpose + data) |
| `service.<id>` 중 AI 서비스 | `includeAi`=포함, `aiService`(서비스명 + product. product가 모름이면 "상품 미확인"), `aiWorkAndData`(purpose + data) |
| AI 서비스 조사 결과 | `aiProviderRetention`, `aiTraining`, `aiHumanReview`, `aiPolicySources`. 출처 URL·적용 상품을 함께 쓴다. 조사 실패면 기본(사용) 문안 + "제공사 자료 미확인" |
| 위탁 서비스 조사 결과 | `subProcessors`, `subProcessingWork`. 하위처리자 목록을 원문에서 읽은 경우에만 업체명을 쓴다. 못 읽었으면 기본(사용) 문안 + "제공사 자료 미확인" |
| 처리 국가가 국외로 확인됨 | `overseas*` 항목 초안 + `legal_review`에 첨부 필요 여부. `includeOverseasConsent`는 법률 검토 전에는 켜지 않고 검토 항목으로 둔다 |
| `office.sensitive` = confirmed | `includeSensitiveConsent`=첨부, `sensitiveItems`(사용자가 말한 항목) |
| `office.provision` = confirmed | `includeProvisionConsent`=첨부, `recipients`·`providedData` |
| `not_applicable` | 해당 범위 기본(비사용) 문안 |
| 사무소 정보 미입력 | `privacyOfficeName` 등은 `[사무소명]` 형식 빈칸 |
| `manual_overrides` | 해당 항목은 사용자 문구 그대로. 재생성 금지 |
