# 예시 사무소 구성 (example-v1)

법률사무소에서 자주 쓰는 서비스 조합(사건관리 프로그램·클라우드 저장·이메일·AI 3종)을 가정해 만든 예시다(2026-11-18 작성). 이용 실태 조사에 근거한 값이 아니다. 권장안도 아니다. 문답을 줄이려고 「이 사무소와 무엇이 다른가」를 묻는 비교 기준으로만 쓴다.

- 예시값은 **제안**이다. 사용자가 「그대로」라고 답해야 `confirmed`가 된다. 답하지 않은 값을 확인 사실로 쓰지 않는다.
- 사용자에게 보여줄 때 「자주 쓰는 서비스 조합을 가정해 만든 예시」라고 밝힌다. 「실제 구성」「1곳의 사례」「표준」「권장」이라고 쓰지 않는다. 조사 근거가 없으므로 「일반적인 사용 패턴에 근거한」이라고도 쓰지 않는다.
- 4절의 법적 판단은 예시 사무소가 내린 판단이다. 사용자의 판단으로 옮기지 않는다(4절 규칙).

## 1. 예시 사무소 서비스 구성

| id | 서비스 | 업무 | 입력 정보 | 예시 요금제 |
|---|---|---|---|---|
| `jurisupport` | 쥬리서포트 | 사건관리 | 당사자 인적사항(주민등록번호 포함), 사건정보, 범죄경력 | 해당 없음(상품별 차이 없음) |
| `onedrive` | 원드라이브 | 클라우드 저장 | 사건자료 | 개인용 |
| `gmail` | 지메일 | 이메일 | 이메일 | Google Workspace |
| `claude` | 클로드 | AI 업무 보조 | 사건정보, 인적사항(주민등록번호 제외), 사건자료, 범죄경력 | 개인용 유료 |
| `gpt` | GPT | AI 업무 보조 | 사건정보, 인적사항(주민등록번호 제외), 사건자료, 범죄경력 | 개인용 유료 |
| `gemini` | 제미나이 | AI 업무 보조 | 사건정보, 인적사항(주민등록번호 제외), 사건자료, 범죄경력 | Google Workspace |

- 「인적사항」은 처리방침에서 성명, 주민등록번호, 주소, 전화번호, 전자우편 주소로 풀어 쓴다. 공개 전 사용자가 확인한다.
- 각 서비스의 공개 조사 결과는 `service-catalog.md`에 있다. 확인일이 6개월 안이면 다시 조사하지 않는다.

## 2. 예시 사무소 사실

| 키 | 예시값 |
|---|---|
| `office.sensitive` | 범죄경력(전과). 쥬리서포트와 AI에 입력 |
| `office.provision` | 없음(위탁 외 제3자 제공 없음) |
| `office.rrn_handling` | 주민등록번호는 법원 제출 서류와 사건관리 프로그램에만 기재한다. AI에는 입력하지 않는다 |
| `office.ai_settings` | AI 모델 학습 옵션 끔, 피드백 제출 안 함 |
| `office.gemini_retention` | 90일 자동 삭제 (Workspace 관리 콘솔에서 고정) |
| `office.refusal_effect` | 민감정보·국외이전 동의를 거부하면 수임·위임사무 처리 불가 |

## 3. 문서 결정

| 결정 | 예시값 | 근거 |
|---|---|---|
| 민감정보 처리 동의서 | 첨부 | 개인정보 보호법 제23조 제1항 제1호(별도 동의) |
| 국외 이전 동의서 | 첨부 | 같은 법 제28조의8 제1항 제1호(별도 동의) |
| 제3자 제공 동의서 | 미첨부 | `office.provision` = 없음 |
| 일반 개인정보 수집 동의 | 받지 않음 | 같은 법 제15조 제1항 제4호(계약 체결·이행) |
| 주민등록번호 | 동의서에 넣지 않음 | 같은 법 제24조의2 제1항은 동의를 예외로 두지 않는다 |
| 상품·요금제 표시 | 공개 문서에 적지 않음 | 같은 법 제26조 제2항, 제30조 제1항, 시행령 제28조 제2항·제31조 제1항은 요금제 공개를 요구하지 않는다. 보관·학습 조건은 적는다 |

조문은 2026-11-18 korean-law로 대조했다(제23조, 제24조의2, 제26조, 제28조의8, 제30조, 시행령 제28조·제31조).

## 4. 예시 사무소의 법적 판단 (채택 여부를 사용자가 정한다)

아래 문안은 예시 사무소가 스스로 판단해 채택했다. 사용자가 A 묶음을 「그대로」로 답해도 이 판단까지 채택한 것으로 보지 않는다.

- 문답 중에는 묻지 않는다. 초안에는 해당 위치에 문안을 넣고 「〔예시 사무소 문안: 채택 여부 결정 필요〕」를 붙인다.
- 각 항목을 `legal_review[]`에 넣는다. 초안 보고의 법률 검토 묶음에 한 번에 보여주고, 사용자가 「채택」·「삭제」·직접 문안 중 하나로 답하게 한다.
- 사용자가 채택하면 표시를 지우고 `manual_overrides`에 넣는다. 답이 없으면 공개용 문서에서 그 문안을 빼고 빈칸으로 둔다.

| id | 문안 | 표시할 주의 |
|---|---|---|
| `rrn.basis` | 「법원은 재판업무 수행을 위하여 필요한 범위에서 주민등록번호를 처리하고, 소송관계인 특정을 위한 개인정보를 관리합니다(민사소송규칙 제76조의2 제1항·제3항). 사무소는 법원에 소송관계인을 특정해 제출하기 위하여 주민등록번호를 처리합니다(개인정보 보호법 제24조의2 제1항 제1호).」 | 민사소송규칙 제76조의2 제1항의 주어는 「법원은」이다. 사무소 판단으로 채택한 문안이다 |
| `refusal.effect` | 「동의하지 않으시면 사무소는 사건을 수임하거나 위임사무를 처리할 수 없습니다.」 | 해당 정보가 위임사무에 필요하다는 전제에서만 쓴다(대법원 2017. 4. 7. 선고 2016도13263 판결이 설명한 최소수집 원칙) |
| `counterparty.overseas` | (문안 없음) | 상대방·사건 관계인 정보는 동의를 받을 수 없다. 국외 AI 입력의 근거를 따로 검토하거나 가명 처리 기준을 둔다 |
| `ai.entrust` | AI 입력을 처리위탁으로 적는다 | 대법원 2016도13263 판결 기준. 제공사가 자기 목적(안전성 플래그 보관 등)으로 쓰는 부분은 제3자 제공 소지가 있다 |
| `onedrive.training` | 제공사 처리방침의 학습 조항을 적는다 | 개인용 원드라이브는 처리방침이 파일을 AI 학습 대상에서 빼지 않는다. 업무용으로 바꾸면 계약 조항이 우선한다 |
