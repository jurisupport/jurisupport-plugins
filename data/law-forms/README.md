# law-forms 공용 서식 서재

자주 쓰는 서식을 kordoc으로 변환해 둔 hwpx와, 칸 매핑(`recipe.json`)·노하우(`노하우.md`)를 함께 담는다. `toolkit/law-forms/install.sh`가 `~/law-forms/shared-library/`로 복사한다.

| 공소청-열람등사-221호 | 공소청사건사무규칙 별지 제221호 열람ㆍ등사 신청서(부표 포함) | 국가법령정보센터 |
| 공소청-동석신청-피해자 | 공소청사건사무규칙 별지 제37호 동석신청서 | 국가법령정보센터 |

| 피해자재판기록열람복사-B1352 | 전산양식 B1352 피해자 재판기록 열람·복사 신청서 | 대한민국 법원 전자소송포털 양식모음 |

각 폴더 구성:

- `form.hwpx` — 원본 hwp를 kordoc 4.24.37 `to-hwpx`로 변환한 서식
- `official.pdf` — 출처가 배포한 PDF(있을 때만). 쪽수 대조용
- `meta.json` — 법령명·별지 번호·공포일자·해시
- `recipe.json` — 필드 이름 → 칸 매핑
- `노하우.md` — 언제 쓰는지, 근거, 주의할 점

서식 개정 여부는 `law_forms.py library check`로 확인한다. 법령·고시는 저작권법 제7조의 보호받지 못하는 저작물이다. 법원 전산양식은 출처를 표시해 쓴다.
