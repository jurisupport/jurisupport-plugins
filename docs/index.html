0먼저 알아둘 것

클로드코드(Claude Code)는 앤트로픽의 인공지능 클로드를 내 컴퓨터 안에서 쓰는 프로그램입니다. 채팅창에 파일을 하나씩 올리는 대신, 클로드가 내 사건폴더를 통째로 직접 읽고 문서를 만들어 저장합니다.

쥬리서포트 플러그인(jurisupport-plugins)은 거기에 한국 송무용 기능을 얹는 무료 공개 패키지입니다. 사건기록 정리, 쟁점 추출, 법령·판례 검증, 준비서면 초안 작성이 하나의 표준 절차로 묶여 있습니다.

legal-terminal은 그 둘을 검은 창 없이 쓰는 앱입니다. 사건폴더·전자소송기록·준비서면·클로드 채팅을 한 화면에 모아 둔, 변호사용 작업 프로그램입니다.

이 안내서는 아무것도 안 깔린 컴퓨터에서 시작해 위 세 가지를 모두 설치하고, 실습용 가상사건으로 준비서면 초안까지 한 바퀴 돌려 보는 것을 목표로 합니다.

검은 화면이 무섭게 느껴져도 괜찮습니다

설치는 검은 창(터미널)에 딱 한 줄을 붙여넣고 엔터를 치는 것이 전부입니다. 나머지는 자동으로 진행되고, 중간에 몇 번 Y 또는 엔터만 누르면 됩니다. 설치가 끝나면 legal-terminal 앱을 써서 검은 창을 아예 안 볼 수도 있습니다.

1준비물 3가지

  • 클로드 Pro 또는 Max 유료 계정 — 월 20달러부터. 이것만은 사람이 직접 가입·결제해야 하며 자동으로 처리되지 않습니다.
  • 인터넷에 연결된 컴퓨터 — Windows 10 22H2 이상 / Windows 11, 또는 macOS.
  • 관리자 비밀번호 — 설치 도중 1~2회 물어봅니다. (윈도우는 "이 앱이 변경하도록 허용하시겠습니까?" 팝업에 예)

Pro와 Max 차이

3검은 창(터미널) 여는 법

설치 명령을 붙여넣을 창을 먼저 엽니다. 쓰는 컴퓨터에 맞는 탭을 누르세요. 이 선택은 아래 모든 단계에 함께 적용됩니다.

  1. 키보드에서 윈도우 키를 누릅니다 (또는 화면 왼쪽 아래 시작 버튼 클릭)
  2. powershell 이라고 입력합니다
  3. 목록에 뜬 Windows PowerShell을 그냥 클릭해서 실행합니다
    → '관리자 권한으로 실행'을 고를 필요 없습니다.
  4. 파란색 또는 검은색 창이 열리면 준비 완료입니다
  1. 키보드에서 커맨드(⌘) + 스페이스를 누릅니다
  2. 터미널 또는 terminal 이라고 입력합니다
  3. 맨 위에 나오는 터미널을 엔터로 실행합니다
  4. 흰색 또는 검은색 창이 열리면 준비 완료입니다

이 안내서의 상자 오른쪽 위 복사 버튼을 누른 뒤, 검은 창에서 마우스 오른쪽 클릭(윈도우) 또는 커맨드+V(맥)를 하면 붙여집니다. 그다음 엔터.

4한 줄 설치 — 이 단계가 핵심입니다

아래 한 줄이 점검 → 설치 또는 업데이트 → 실습자료 다운로드까지 한 번에 처리합니다. 이미 깔려 있으면 건너뛰고, 오래됐으면 최신으로 올리고, 없으면 물어본 뒤 설치합니다.

윈도우 · PowerShell 
irm "https://raw.githubusercontent.com/jurisupport/claudecode-songmu-seminar2/main/setup-check.ps1?cache=legalproc" | iex

중간에 팝업이 여러 번 뜹니다

"이 앱이 디바이스를 변경하도록 허용하시겠습니까?" 창이 나오면 예를 누르세요. 여러 번 나올 수 있고, 다른 창 뒤에 가려져 있을 수도 있습니다. 화면이 멈춘 것 같으면 작업표시줄의 노란 방패 아이콘을 확인하세요.

회사 보안정책에 막혔을 때

irm ... | iex 가 차단되면 새 PowerShell 창에 아래 4줄을 붙여넣으세요. 스크립트가 열리면 선택지에서 S(보안·진단 모드)를 고릅니다.

$p = "$env:TEMP\claudecode2-setup-check.ps1"
iwr "https://raw.githubusercontent.com/jurisupport/claudecode-songmu-seminar2/main/setup-check.ps1?cache=legalproc" -OutFile $p -UseBasicParsing
Unblock-File $p
powershell.exe -NoProfile -ExecutionPolicy Bypass -NoExit -File $p

실패해도 바탕화면에 진단 ZIP을 남기고 실습자료 다운로드는 계속 진행됩니다.

맥 · 터미널 
bash <(curl -fsSL https://raw.githubusercontent.com/jurisupport/claudecode-songmu-seminar2/main/setup-check.sh)

실습자료는 ~/Downloads/클로드코드2차자료 에 받아집니다. 전체 10분쯤 걸립니다.

비밀번호를 물어보면

홈브루(Homebrew) 설치 때 맥 로그인 비밀번호를 한 번 묻습니다. 입력해도 화면에는 아무 글자도 보이지 않습니다. 정상이니 그대로 치고 엔터를 누르세요.

설치가 끝날 때까지 창을 닫지 마세요

글자가 빠르게 올라가는 동안은 정상 작동 중입니다. 몇 분간 멈춘 것처럼 보여도 기다리세요. 노트북은 전원을 연결하고 절전으로 꺼지지 않게 해 두면 좋습니다.

실습자료 없이 프로그램만 깔고 싶다면 (펼치기)

윈도우 · PowerShell 
claude.cmd

PowerShell에서 그냥 claude를 치면 실행 정책 오류가 날 수 있습니다. 뒤에 .cmd를 붙이세요. (시작 메뉴의 Git Bash에서 쓸 때는 그냥 claude입니다.)

터미널 창을 완전히 닫았다가 새로 연 뒤, 아래를 입력하고 엔터.

맥 · 터미널 
claude
  1. 브라우저가 자동으로 열립니다
  2. 2번 단계에서 만든 클로드 Pro 계정으로 로그인
  3. 권한 승인 버튼을 누릅니다

클로드코드를 빠져나올 때는 /exit를 입력하거나 Ctrl+C를 두 번 누르면 됩니다.

7legal-terminal — 검은 창 대신 쓰는 앱

개발자에게 VS Code가 있다면 송무 변호사에겐 legal-terminal이 있습니다. 사건폴더 · 전자소송기록 PDF · 준비서면 · 클로드 채팅을 한 화면에서 다루는 앱입니다.

처음 쓰는 분께는 검은 창보다 이쪽을 강하게 권합니다. 기록 PDF를 왼쪽에 띄워 놓고 오른쪽 채팅창에 바로 물어볼 수 있어, 지금 무엇을 보고 있는지 헷갈리지 않습니다.

9실습 — 가상사건으로 30분

실습 사건은 가상사건입니다

김민철 vs 이정숙 · 대여금 사건으로, 인적사항·금액·계좌·사건번호는 모두 허구이며 실재 인물·사건과 무관합니다.

사건 개요

원고가 2013~2015년 4회에 걸쳐 피고에게 합계 9,000만원을 빌려줌 → 피고가 1,000만원 일부변제 후 잔액 8,000만원 미회수 → 2024년 차용증을 받았으나 변제기(2025.12.31.) 도과 → 피고는 아파트 매도·주소 이전 정황 → 2026년 소제기. 피고는 소멸시효 완성을 주장합니다.

피고의 항변 4가지

  1. 송금은 대여가 아니라 사업 투자·동업이었다
  2. 설령 대여라도 마지막 송금일부터 10년이 지나 소멸시효 완성
  3. 일부변제는 명절·생일 인사일 뿐 채무승인이 아니다
  4. 2024년 차용증은 시효 완성을 모른 채 작성 → 시효이익 포기 아니다

미션 — 여러분은 원고(김민철)의 소송대리인입니다. 위 4가지 항변을 반박하는 준비서면 1~2페이지를 클로드코드로 작성합니다.

0단계. 사건폴더 열기

4번 단계의 한 줄을 실행했다면 Downloads/클로드코드2차자료 안에 실습사건_세션1_대여금 폴더가 있습니다. PDF 13개(소장·갑1~5호증·답변서·을1호증·변론준비기일조서)가 들어 있습니다.

권장 — legal-terminal에서 열기: 앱에서 새 사건 → 작성서류 폴더를 누르고 실습사건_세션1_대여금 폴더를 선택하면, 그 사건 기준 Claude Agent 탭이 열립니다. 이후 모든 프롬프트는 Agent 채팅창에 붙여넣습니다.

순서는 다음처럼 진행해줘.
1. 사건번호, 서면 유형, 제출기한, 특별 지시사항 인테이크
2. JuriSupport MCP가 있으면 사건 메타를 먼저 확인하고, 없으면 case-index 또는 사건 폴더에서 확인
3. 사건기록을 읽고 쟁점표와 증거 대응표 작성
4. legal-books, korean-law, beopgoeul-search 순서로 근거 확인
5. 본문을 쓰기 전에 목차만 제안하고 내 승인을 기다리기
6. 승인 후 Markdown 초안 작성
7. 법령·판결번호·직접인용을 검증 리포트로 따로 점검
각 단계가 끝나면 다음 단계로 넘어가기 전에 요약하고 멈춰줘.

사고가 나는 지점 잠그기

실제 업무에서 반복적으로 사고가 났던 지점들입니다. 각각을 막는 프롬프트를 그대로 쓰세요.

① 판례 환각 골라내기

방금 네가 인용한 판례를 모두 표로 정리해줘.
- 열: 사건번호 / 선고일 / 쟁점 / 네가 쓴 법리 / 실제 조회 여부 / 원문 확인 필요 부분
- 실제로 조회하지 못한 판례는 절대 단정하지 말고 "미확인"이라고 써줘.
- 주문과 판시사항이 네 설명과 맞는지도 따로 표시해줘.

② 발신인·수신인 뒤바뀜 방지 (내용증명 수정 시 빈발)

수정 전에 당사자 구도부터 확인해줘.
- 발신인/작성 주체: A
- 수신인/상대방: B
- 우리 입장: B의 채무불이행을 이유로 이행을 촉구한다
- 유지할 톤: 단정적이되 감정적 표현은 피한다
위 구도를 표로 먼저 확인한 뒤, 기존 문서에서 이 구도와 어긋나는 문장만 찾아 수정안을 제시해줘.

③ 최신본 덮어쓰기 방지

파일을 수정하기 전에 반드시 디스크의 최신본을 다시 읽어줘.
- 파일명, 수정시각, 전체 구조를 먼저 요약
- 내가 직접 수정한 문단은 보존
- 요청받은 부분만 최소 수정
- 수정 후 변경된 문단과 보존한 문단을 나눠 보고
- 확실하지 않으면 덮어쓰지 말고 충돌 가능성을 먼저 알려줘.

④ 사실주장 원자료 대조

초안의 사실주장을 모두 점검해줘.
- 열: 초안 문장 / 근거 파일 또는 호증 / 원문 위치 / 확실·불확실·근거없음 / 수정안
- 자백, 반성, 승인, 고의, 기망, 악의, 변제 약속 같은 민감한 표현은 특히 엄격하게 봐줘.
- 근거 없는 문장은 삭제하거나 "주장할 수 있음" 수준으로 낮춰줘.

⑤ AI 말투 줄이기

아래 문단을 의미는 유지하면서 준비서면답게 다듬어줘.
- 과장된 비유, 긴 대시, "중요합니다/핵심입니다" 같은 LLM 말투 금지
- 화살표나 도식 대신 문장으로 쓸 것
- 상대방을 불필요하게 자극하는 표현은 낮출 것
- 수정 이유를 3줄 이내로 설명할 것

이 밖에 견적 누락 방지, 증거설명서 표 만들기, 스타일가이드 자산화 등 더 많은 프롬프트는 실습 명령어 핸드아웃에 들어 있습니다.

지켜야 할 5가지

변호사 비밀유지의무와 직결됩니다. 설치 후 jurisupport-plugins/guides/00_security.md 를 한 번 정독하시길 권합니다.

  1. 인공지능 서비스의 "내 대화를 학습에 사용" 동의는 거부
  2. 무료 번역기·무료 OCR 사이트에 사건자료 업로드 금지
  3. 사건폴더를 외부 공유링크로 열지 않기
  4. 클로드코드에 "이 자료 외부로 보내줘"라고 시키지 않기
  5. 일반 카톡·텔레그램으로 사건자료 주고받지 않기

데이터 보호 장치는 보조 수단입니다

의뢰인 정보가 외부로 나가려 할 때 감지·차단하는 장치가 들어 있지만, 완전한 유출 방지를 보장하지 않습니다. 최종 판단은 사용하는 변호사의 몫입니다.

가장 중요한 한 가지 — 초안은 AI, 검증은 변호사

인용한 판결번호·법령 조문은 제출 전 반드시 직접 재확인하세요. 결과물의 정확성·법적 적합성 검증, 의뢰인 정보 보호, 법원·의뢰인 제출 전 최종 검토는 모두 사용 변호사 본인의 책임입니다.
