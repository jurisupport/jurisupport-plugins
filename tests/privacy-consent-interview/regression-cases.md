# 회귀 사례 — privacy-consent-interview

판정은 질문 문자열이 아니라 **다음에 묻는 주제 키와 질문할 이유**로 한다. 근거는 각 실행 폴더의 `transcript.md`(사용자에게 보인 문답)와 `state-turnN.json`(턴별 상태)이다. 모든 자료는 가상이며 실제 식별번호를 넣지 않는다.

## 판정 기준 (HANDOFF 7절)

| ID | 사례 | 필수 판정 | 실행 위치 |
|---|---|---|---|
| R1 | 실제 재현 대화의 두 답변 | 업무·입력 정보 재질문 0회. 필요하면 클로드 상품만 질문 | A 턴 2~3 |
| R2 | 같은 사실을 다른 표현으로 묻기("전달 자료"·"제공 정보"·"입력 데이터") | 같은 주제 키. 답한 키는 다시 묻지 않음 | A·B·C 전체 `asked[]` |
| R3 | 재수탁자 등 제공사 자료 검증 실패 | 사용자 업무·자료 재질문 0회. 조사 과제는 `research[]`에 남음 | C |
| R4 | 12개 메시지를 넘는 대화 | 앞서 확정한 서비스·업무·자료 유지 | B (7턴 이상 = 14메시지 이상) |
| R5 | "AI에도 동일한 정보" | 기존 정보와 연결(`ref`). 목록 재작성 요구 0회 | A 턴 3 |
| R6 | "요금제는 모르겠어요" | `unknown_by_user`. 요금제 재질문 0회. 상품별 조건 단정 0회 | B |
| R7 | 한 답변에 서비스명·상품·업무가 함께 있음 | 한 턴에 모두 반영. 각각 재질문 0회 | C 턴 2 |
| R8 | "주민번호는 빼고 이름만" 정정 | 정정 범위만 갱신. 이전 값이 초안에 남지 않음 | B |
| R9 | 직접 고친 문안 뒤 다른 항목 수정 | 수동 문안 유지 | B |
| R10 | 필요한 사실을 다 답했거나 초안 요청 | 초안 제시. 이유 없는 새 질문 0회 | A 끝, B "일단 초안" |
| R11 | 공식 문서 조회 실패 | 읽었다고 주장 0회. 조건 추정 0회. 인테이크 반복 0회 | C |
| R12 | 초안 뒤 새 서비스 추가 | 새 서비스 주제만 확인. 기존 인테이크 유지 | B |

## 가상 사무소 사실표

사용자 역할을 하는 사람은 질문에 아래 사실로만 답한다. 묻지 않은 사실을 미리 말하지 않는다(사례에 적힌 답변 제외).

### A. 정상 완료 (실제 재현 대화)

- 서비스: 사건관리는 쥬리서포트, AI는 클로드.
- 쥬리서포트에 보내는 정보: 의뢰인 인적사항(주민등록번호 포함), 사건정보 일체.
- 클로드에 넣는 정보: 쥬리서포트와 같음.
- 클로드 상품: Claude Team.
- 민감정보: 형사사건에서 전과 기록, 손해배상 사건에서 진단서를 다룬다.
- 제3자 제공: 법원·수사기관 제출 외에 따로 넘기는 곳 없음.
- 고정 답변: 턴 2 "사건관리는 쥬리서포트, ai는 클로드를 이용해요" / 턴 3 "사건관리 업무를 위해 의뢰인의 인적사항(주민번호 포함), 사건정보 일체 제공. ai에도 동일한 정보 제공"

### B. 모름·정정·긴 대화·수동 문안·서비스 추가

- 서비스: 클로드, 쥬리서포트.
- 쥬리서포트: 사건 일정·기록 관리, 의뢰인 이름·연락처·주민등록번호·사건 내용.
- 클로드: 서면 초안 작성. 처음에는 쥬리서포트와 같은 정보라고 답한다.
- 클로드 요금제: 모른다.
- 정정(초안 전 한 턴): "클로드에는 주민번호는 빼고 이름만 넣어요".
- 민감정보·제3자 제공: 질문을 받으면 "일단 초안 보여줘"로 넘어간다.
- 초안 후: 권리행사 접수 방법을 직접 문구로 지정 → 구글 드라이브(사건 서류 백업) 추가 → 상담정보 보유기간을 6개월로 변경.

### C. 제공사 자료 실패·한 번에 여러 사실

- 고정 답변 턴 2: "Claude Team을 서면 초안 작성에 쓰고, 사건관리는 '케이스노바'라는 프로그램을 써요. 둘 다 의뢰인 이름, 연락처, 사건 내용을 넣어요."
- 케이스노바: 가상 서비스명. 공식 자료가 없어야 정상이다.
- 민감정보: 처리하지 않는다. 제3자 제공: 없다.
- 케이스노바 재수탁자를 물으면: "그건 모르겠어요" (이 질문 자체가 R3 위반 신호다).

### D. 물었지만 답을 받지 못한 질문 (B 5턴 결함 재검증, 스킬 수정 후)

- 결함: B 5턴에서 민감정보 질문에 사용자가 정정만 답했는데, 스킬이 그 주제를 "이미 물음"으로 제외했다.
- 기대: 답을 받지 못한 주제는 `needed`로 남고 `unanswered` 사유로 한 번 더 묻는다. "모름"을 받으면 그 뒤에는 묻지 않는다.
- 고정 답변: 턴 2 "쥬리서포트로 사건관리해요. 의뢰인 이름이랑 연락처 넣어요." / 민감정보 질문에 "아 그리고 시행일은 2027. 1. 1.로 해주세요" / 재질문에 "모름" / 제3자 제공에 "없어요".

### E. 조사 실패를 "없음"으로 메우지 않음 (D 초안 결함 재검증, 스킬 수정 후)

- 결함: D에서 쥬리서포트 처리방침 조사에 실패했는데 초안이 "국외 이전 없음"을 전제로 썼다. A·D는 조사 실패, B는 같은 처리방침을 읽어 국외 재수탁자를 확인했다.
- 기대: 한글·영문 이름 검색과 공식 도메인 직접 조회를 시도하고 `attempts`를 남긴다. 실패하면 처리 국가·재수탁자를 빈칸 `[미확인]`으로 둔다.
- 고정 답변: 턴 2 "쥬리서포트로 사건관리해요. 의뢰인 이름이랑 연락처 넣어요." / 턴 3 "일단 초안 보여줘".
